# ShadowImage v0.2.0

首个完整的独立库版本：通过一个自定义 SHP2 码流，先显示全图轮廓，再随着下载持续增加细节。纯 JavaScript 解码，不依赖 WASM 或浏览器原生渐进图片格式支持。

## 功能

- 整数 5/3 小波、全图位平面增量、按块选择 varint / 零游程 / Rice 编码。
- RGB/RGBA 精确重建；可选有损颜色模式，alpha 保持完整精度。
- 流式校验、资源限制、截断检测、可取消与重启的播放器。
- Canvas 展示、可选 Worker、主线程分片及能力回退。
- 独立编码入口、TypeScript 类型、离线编码工具和真实 HTTP 限速演示。

## 下载与使用

| 文件 | 用途 |
|---|---|
| `shadow-image-0.2.0.tgz` | npm 可安装包：`npm install ./shadow-image-0.2.0.tgz` |
| `shadow-image-browser-0.2.0.zip` | 免构建浏览器文件、原创示例码流、HTML 示例与文档 |
| `SHA256SUMS` | 两个发布包的 SHA-256 校验值 |

ZIP 解压后，在解压出的目录运行 `python -m http.server 8080`，访问 `http://localhost:8080`。将 `dist/` 完整部署到网站，保留 `player/worker.js` 的相对路径；接入示例见仓库 README。

离线将 PNG/JPEG/WebP 等输入转换为自定义码流：下载源码，执行 `npm ci`，然后 `npm run encode -- input.png output.shp --base=32 --omit=0`。离线图像读取依赖不会进入网页运行时。

## 验证与体积

- 网页入口 + 可选 Worker 合计 7,878 bytes gzip；编码器单独提供。
- 13 项 Node 测试通过，12 张真实图片在三种基础层尺寸下精确还原。
- 24 次浏览器像素哈希校验通过（12 图片 × 主线程 / Worker）。
- Chromium、Edge、Windows WebKit 的真实 HTTP 流播放已验证；Firefox、Chrome 正式版、Safari 和手机真机未完成验证。

这是 0.x 版本，SHP2 协议尚未冻结。默认图片上限 400 万像素；高分辨率和多图并发仍需按应用预算管理内存。没有响应流能力时会显式回退为完整下载后解码。兼容性与性能实测见 `reports/VALIDATION.md`。

发布包只包含库代码、文档与原创程序生成示例，不包含测试用第三方图片。未发布到 npm registry，可直接安装本 Release 的 `.tgz`。
